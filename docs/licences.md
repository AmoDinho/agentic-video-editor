# Licences checked in Phase 0

## Remotion

This is a personal project, so Remotion's free licence applies. The Player is
used only to preview a cut in the browser. FFmpeg still does the final export.
No Remotion company licence is required. Do not add Remotion branding removal
or a paid-feature path.

## Diffusion Studio

`diffusionstudio/core` is Mozilla Public License 2.0.

MPL-2.0 allows use inside a larger work, but any file that contains Diffusion
Studio source stays under MPL, must keep its notices, and must ship its source.
That is a real obligation for a personal project that may later be shared.

Decision: do not copy Diffusion Studio source. The ideas we keep are already in
the spec and are not their code: the cut is the source of truth, the media bin
is grouped by camera and day, the agent sits beside the player, and styles are
reusable presets. Editing operations in this repo are our own, on our EDL.
